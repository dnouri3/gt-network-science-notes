Course Modules

Module 1: Foundations of Network Science

Lectures: L1-L2

Learning Objectives

  • Understand what network science is and its applications
  • Master fundamental graph theory concepts
  • Learn network representations (adjacency matrix/list)
  • Understand different types of graphs (directed, weighted, bipartite)
  • Master essential algorithms (shortest paths, random walks)

Topics Covered

  • L1: Introduction to Network Science
    • Complex systems and network representation
    • Network centrality introduction
    • Communities and network dynamics
    • History and birth of network science
  • L2: Graph Theory Fundamentals
    • Graphs, paths, and cycles
    • Directed and weighted graphs
    • Strongly connected components and DAGs
    • Dijkstra’s algorithm and random walks
    • Min-cut/Max-flow problems
    • Bipartite graphs and applications

Prerequisites: Linear algebra, basic probability theory

Module 2: Network Properties and Metrics

Lectures: L3-L5

Learning Objectives

  • Analyze degree distributions and their implications
  • Understand the friendship paradox and its applications
  • Master power-law distributions and scale-free networks
  • Calculate and interpret clustering coefficients
  • Understand the small-world phenomenon

Topics Covered

  • L3: Degree Distribution and Friendship Paradox
    • Degree distribution moments and special cases
    • The friendship paradox and immunization strategies
    • Erdős-Rényi random graphs G(n,p)
    • Connected components and phase transitions
    • Degree correlations and assortativity
  • L4: Power-Law Networks
    • Scale-free property and its implications
    • Random failures vs targeted attacks
    • Configuration model
    • Preferential attachment mechanism
    • Superspreaders case study
  • L5: Clustering and Small World
    • Local and global clustering coefficients
    • Weighted network clustering
    • Small-world phenomenon
    • Network motifs and patterns

Prerequisites: Module 1, statistics fundamentals

Module 3: Centrality and Communities

Lectures: L6-L8

Learning Objectives

  • Master various centrality metrics and their applications
  • Understand community structure in networks
  • Learn community detection algorithms
  • Analyze overlapping and dynamic communities
  • Apply centrality and community concepts to real networks

Topics Covered

  • L6: Centrality Metrics
    • Degree, betweenness, closeness centrality
    • Eigenvector centrality and PageRank
    • Katz centrality and hubs/authorities
    • Core decomposition (k-core, k-shell)
  • L7: Community Detection
    • Modularity and quality metrics
    • Girvan-Newman algorithm
    • Louvain and label propagation
    • Spectral clustering methods
  • L8: Advanced Community Detection
    • Overlapping communities (CFinder, link clustering)
    • Community benchmarks (GN, LFR)
    • Dynamic community detection
    • Participation coefficient and within-module degree
    • Applications in metabolic networks and climate science

Prerequisites: Module 2, linear algebra (eigenvalues)

Module 4: Network Dynamics and Spreading

Lectures: L9-L11

Learning Objectives

  • Model epidemic spreading on networks
  • Understand information diffusion and cascades
  • Analyze influence maximization problems
  • Apply spreading models to real-world scenarios
  • Understand the role of network structure in spreading

Topics Covered

  • L9: Epidemic Models
    • SI, SIS, and SIR models
    • Basic reproductive number R₀
    • Degree block approximation
    • Epidemic thresholds in scale-free networks
    • Computational epidemiology
    • Effective distance concept
  • L10: Information Diffusion
    • Diffusion and cascade models
    • Linear threshold and independent cascade
    • Influence maximization (submodular optimization)
    • Cascades in networks with communities
    • Brain network diffusion applications
  • L11: Opinion Dynamics
    • Voter model and consensus formation
    • DeGroot model
    • Bounded confidence models
    • Polarization and echo chambers
    • Social influence empirical studies

Prerequisites: Module 3, differential equations basics

Module 5: Network Models and Applications

Lectures: L12-L14

Learning Objectives

  • Understand network generation models
  • Learn to model real-world network properties
  • Apply network science to practical problems
  • Design networks with desired properties
  • Understand current research directions

Topics Covered

  • L12: Network Formation Models
    • Preferential attachment (BA model)
    • Mathematical analysis and degree dynamics
    • Link-copy model
    • Generating networks with communities
    • Optimization-based formation
    • Hierarchical graph models
  • L13: Temporal and Multilayer Networks
    • Time-varying networks
    • Multilayer and multiplex networks
    • Network of networks
    • Interdependent networks
    • Temporal motifs and patterns
  • L14: Applications and Future Directions
    • Biological networks
    • Social media and online networks
    • Infrastructure and transportation
    • Economic and financial networks
    • Machine learning on graphs
    • Current research frontiers

Prerequisites: All previous modules

Study Resources

  • Primary Textbook: A-L. Barabási, Network Science, 2015
  • Secondary Text: D. Easley and J. Kleinberg, Networks, Crowds and Markets, 2010
  • Advanced: M. Newman, Networks: An Introduction, 2018

Prerequisites

Mathematical Background

  • Linear Algebra: Matrices, eigenvalues, eigenvectors
  • Probability: Distributions, expected values, stochastic processes
  • Calculus: Derivatives, basic differential equations
  • Statistics: Hypothesis testing, regression, distributions

Programming Skills

  • Python: NetworkX library experience helpful
  • Data Structures: Graphs, trees, hash tables
  • Algorithms: Graph traversal, sorting, searching

Course Learning Outcomes

Upon completion, you will be able to:

  1. Analyze complex networks using appropriate metrics and methods
  2. Model real-world systems as networks and understand their properties
  3. Apply network science concepts to solve practical problems
  4. Evaluate network robustness, efficiency, and other characteristics
  5. Design networks with desired properties for specific applications
  6. Implement key algorithms for network analysis
  7. Interpret research papers in network science
  8. Conduct basic research in network science applications
